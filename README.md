1. 核心架构：基于大语言模型的闭环控制系统  
Mingcrap 是一个融合大语言模型（LLM）推理能力与本地系统交互接口的自主 Agent 框架。其任务执行基于以下闭环流程：  
 * 感知（Perception）：通过 Streamlit 用户界面接收用户的非结构化自然语言指令。  
 * 规划（Planning）：利用模型生成思维链，将复杂目标拆解为可执行的 Shell 指令（RUN_CMD 协议）。  
 * 执行（Execution）：借助 Python subprocess 模块，在宿主机环境中调用系统级工具。  
 * 反馈（Feedback）：捕获标准输出（stdout）与错误流（stderr），并将其作为上下文返回给 LLM，用于结果评估与错误修正。

2. 安全工程：多层级拦截机制  
针对 AI 代理可能引发的系统风险，本项目设计了两层安全防护：  
 * 启发式扫描：在执行层预设 danger_keywords 列表（如 rm、del、shutdown 等），自动识别并拦截高危指令。  
 * 人机回路（Human-in-the-Loop）校验：利用 Tkinter 构建模态对话框，强制将控制权交还物理用户，未经明确授权不得执行任何写操作。

3. 采用 Windows 批处理（.bat）脚本作为启动器，详见《部署教程.txt》。

4. 开发者总结  
> “Mingcrap 不只是一个聊天机器人，更是一款具备环境感知能力与自我修正机制的终端操作代理。它证明，借助恰当的提示工程与安全拦截设计，大语言模型可以安全地作为生产力工具，直接参与底层系统管理。”
